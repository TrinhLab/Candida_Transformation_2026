# Proteomics Analysis Pipeline: Script 2 (Venn Diagrams)

This script takes the differential expression outputs generated by Script 1 and dynamically generates four-way Venn diagrams to visualize overlapping protein sets across transformation conditions. It also extracts mutually exclusive sets for downstream pathway analysis.

### Prerequisites
* R (>= 4.0)
* CRAN packages: `VennDiagram`, `grid`

### Inputs
* **Upregulated DEPs:** A CSV file of significantly upregulated proteins (e.g., `UpregulatedDEPs_limma_7-13-26.csv`).
* **Downregulated DEPs:** A CSV file of significantly downregulated proteins (e.g., `DownregulatedDEPs_limma_7-13-26.csv`).
*(Note: These files are generated by filtering the outputs of Script 1 for LogFC >= 1 or <= -1 and adj.P.Val <= 0.05).*

### Outputs
* `_Upregulated_Venn.png` & `_Downregulated_Venn.png`: High-resolution Venn diagrams.
* `_Upregulated_UniqueSets.csv` & `_Downregulated_UniqueSets.csv`: Data frames containing the mutually exclusive proteins for every possible intersection.

### Usage
Update the `FILE_UP_DEPS` and `FILE_DOWN_DEPS` variables in the User Configuration block, then run the script.
